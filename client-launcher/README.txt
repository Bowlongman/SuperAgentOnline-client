Super Agent Online · Windows Web 游戏客户端

使用方法
1. 将 ZIP 解压到任意普通文件夹。
2. 双击 SuperAgentOnline.Client.exe。
3. 输入运行中主机的 http 或 https 地址，点击“连接游戏”。
4. 游戏将在独立 Microsoft Edge 窗口中打开。关闭窗口即可退出游戏。
   启动器可保留，以便更换主机地址并重新连接。

默认连接地址为 https://superagentonline.com。连接其他主机时，请填写主机提供的地址。
如果你在自己的电脑运行主机，可以填写 http://127.0.0.1:18974。
请输入地址的协议、主机名与可选端口，不填写页面路径或查询参数。

运行条件
Windows 10 / Windows 11、.NET Framework 4.5 或更新版本、Microsoft Edge。
客户端通过网络使用主机提供的 Web 游戏，主机必须在线。
遇到无法连接提示时，检查地址、主机运行状态、网络和 HTTPS 证书后重试。

这个包只含游戏启动器和本说明。启动器需要已有的在线主机。
Windows 可能对未签名的 EXE 显示安全提示。请从可信官网获取下载包并核对官网公布的 SHA256。
