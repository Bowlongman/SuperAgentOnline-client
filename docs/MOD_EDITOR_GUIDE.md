# MOD 编辑器手册

打开[工坊工作台](https://superagentonline.com/workshop-editor)，使用游戏账号登录。网页编辑器、HTTP 和 MCP 共用同一工作区。草稿及上传资源由当前账号管理，草稿操作与运行中的世界隔离。

1. 点「新建草稿」，填写标题、唯一 MOD ID、版本、作者和许可。可选填当前已装载的基准 MOD，或导入完整的格式 4 包 JSON。
2. 搜索建筑后选中实例，可替换模型、调整占地和入口，或新增建筑。地形编辑以整数格坐标指定道路、桥面、水面或边界及高度。上传模型使用不超过 64 MiB 的自包含 GLB。选中已上传资源后，将替换操作加入批次。
3. 点「应用到草稿」提交待应用批次，再比较基准版本和当前草稿。红格表示声明的碰撞占地，绿色表示入口，线框表示感知范围。占地是相对于建筑原点的整数格偏移，入口使用世界坐标。换模型后应检查三者是否需要调整。
4. 查看「变更与冲突」，核对基准过期、覆盖和占地提示。并发修改导致修订过期时，重新读取草稿再决定是否重试。需要撤销已保存的编辑，可从历史恢复为新的草稿修订。
5. 校验当前草稿，按返回的问题修正。也可导出 ZIP，内含包 JSON、所引用的 GLB 和 SHA-256 清单。准备发布新内容时更新包版本并应用，再点「发布到工坊」。

发布只创建工坊记录并排队校验。主机管理员另行选择装载，主机针对当前世界重新检查，成功才生效。预检通过后仍应试玩，检查通行、入口和实际动作。
